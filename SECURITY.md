# Security Policy

DotStories runs code and AI models on people's own computers, so we take security seriously. Thank you for helping keep
the community safe.

## Report a vulnerability

**Please don't open a public issue.** Report it privately on GitHub:

👉 [Report a vulnerability](https://github.com/Dayonel/dotstories/security/advisories/new)

Please include:

- what is affected (website, desktop app, engine, a dot) and the version;
- the steps to reproduce it, or a proof of concept;
- what an attacker could do with it.

## What happens next

- We reply as soon as we can, usually within a few days.
- We keep you updated while we work on a fix.
- When it is fixed, we publish an advisory and credit you, unless you prefer not to be named.

Please give us reasonable time to fix the issue before you share it publicly, and don't access other people's data or
disrupt the service while testing.

## Supported versions

| Part | Supported |
|---|---|
| Website ([dotstories.com](https://dotstories.com)) | The live site (`main`) |
| Desktop app and engine | The [latest release](https://github.com/Dayonel/dotstories/releases/latest) |

## Out of scope

- Problems in the AI models themselves: report them to the model's maker (see each model's page on
  [dotstories.com/terms](https://dotstories.com/terms)).
- Harmful or illegal content on the site: report it as described in the [Terms](https://dotstories.com/terms).
